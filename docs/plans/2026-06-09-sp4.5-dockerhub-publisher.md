# SP4.5 — Docker Hub Publisher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish each multi-arch OCI image to GHCR **and** Docker Hub from a single build pass (build-once-push-many), with Docker Hub credentials supplied env-only and the leg gracefully optional.

**Architecture:** `OciPublisher` is changed from one registry to a `registries: Sequence[str]`. Per item it runs `buildah bud` + `manifest create`/`add` **once** (tagged on the primary/first registry), then loops the registries doing `manifest push` + `skopeo copy :latest` to each. The `mh publish --oci --registry` flag becomes repeatable. `forge-release.yml`'s `publish-oci` job logs into both registries (`--password-stdin`, env-only) and calls `mh publish` once with both `--registry` flags; the Docker Hub leg is added only when `DOCKERHUB_TOKEN` is present.

**Tech Stack:** Python 3.12, Click + `CliRunner`, buildah/skopeo (daemonless), GitHub Actions, actionlint, container-first `./dev run`, `make ci` host gate.

---

## Locked decisions (from SP4 spec §6/§9 + user confirmation 2026-06-09)

1. **Build-once-push-many** (user-confirmed, the key design call): the cross-arch `buildah bud` under qemu is the slowest leg; it must run **once**, not once per registry. The local manifest is tagged on the **first** registry in the list; each registry then receives a `manifest push` of that one local manifest + a per-registry `skopeo copy :latest`.
2. **GHCR primary, Docker Hub additive mirror.** The publisher treats all registries uniformly, but the *workflow* always includes GHCR and only adds Docker Hub when `DOCKERHUB_TOKEN` is non-empty — so an un-configured deployment still publishes to GHCR with no failure.
3. **Credentials env-only, never argv** (regression guard, same rule as SP2 signing): `buildah login … --password-stdin`; creds forwarded value-less through `./dev run` (`-e DOCKERHUB_TOKEN`, no `=value`).
4. **Docker Hub namespace is config, not secret:** repo variable `vars.DOCKERHUB_NAMESPACE`, fallback `docker.io/sckyzo`. Docker Hub repos are exactly `docker.io/<namespace>/<repo>`, so the namespace passed as a `--registry` value is `docker.io/sckyzo` (the publisher appends `/<name>`).
5. **Constructor signature change is allowed** (greenfield big-bang exception for monitoring-hub): `registry: str` → `registries: Sequence[str]`. No back-compat shim. All call sites and tests are updated in the same increment.
6. **Single-registry behaviour is byte-identical to today.** With `registries=[ghcr]`, the local tag equals the push ref, so the emitted command sequence is exactly the pre-SP4.5 one. This is asserted by keeping the existing test's command assertions intact (only the kwarg name changes).

## Deployment prerequisites (NOT blocking this PR — operator action)

- Create a Docker Hub access token (Account Settings → Security → New Access Token, **Read & Write**).

- Optionally add repo variable `DOCKERHUB_NAMESPACE` (defaults to `docker.io/sckyzo`).

"""OCI publisher (spec §5.7): build a multi-arch manifest once, push to each registry.

For each ``<staging>/<name>/`` build context emitted by ``mh build`` (Dockerfile +
per-arch binaries), build one image per present arch with ``buildah bud --arch``,
assemble a single manifest list tagged on the **primary** (first) registry, then
push that one local manifest to every configured registry plus a ``:latest`` copy.
Building once and pushing N times keeps the slow cross-arch ``buildah bud`` step
off the critical path for mirror registries (GHCR primary, Docker Hub mirror).
Daemonless and rootless — runs in the dev image with no docker socket. Gated in
CI (needs qemu/binfmt for cross-arch and registry auth).
"""

from __future__ import annotations

from collections.abc import Mapping, Sequence
from pathlib import Path

from forge.domain.errors import PublishError
from forge.packaging.runner import CommandRunner

# Standard publish set; only arches whose binary is staged are actually built.
_ARCHES = ("amd64", "arm64")


class OciPublisher:
    def __init__(
        self,
        *,
        registries: Sequence[str],
        versions: Mapping[str, str],
        runner: CommandRunner,
        tls_verify: bool = True,
    ) -> None:
        if not registries:
            raise ValueError("at least one registry is required")
        self._registries = tuple(registries)
        self._versions = versions
        self._runner = runner
        self._tls_verify = tls_verify

    def publish(self, staging: Path) -> None:
        for context in sorted(p for p in staging.iterdir() if p.is_dir()):
            self._publish_one(context)

    def _publish_one(self, context: Path) -> None:
        name = context.name
        version = self._versions[name]
        arches = [a for a in _ARCHES if any(context.glob(f"*-{a}"))]

        # Build once, tagged on the primary (first) registry.
        local = f"{self._registries[0]}/{name}:{version}"
        for arch in arches:
            self._run(["buildah", "bud", "--arch", arch, "-t", f"{local}-{arch}", str(context)])
        self._run(["buildah", "manifest", "create", local])
        for arch in arches:
            self._run(["buildah", "manifest", "add", local, f"{local}-{arch}"])

        # Push the single local manifest to every registry, plus :latest.
        for registry in self._registries:
            image = f"{registry}/{name}"
            ref = f"{image}:{version}"
            self._push(local, ref)
            self._copy_latest(ref, image)

    def _push(self, local: str, ref: str) -> None:
        push = ["buildah", "manifest", "push", "--all"]
        if not self._tls_verify:
            push.append("--tls-verify=false")
        self._run([*push, local, f"docker://{ref}"])

    def _copy_latest(self, ref: str, image: str) -> None:
        copy = ["skopeo", "copy"]
        if not self._tls_verify:
            copy += ["--src-tls-verify=false", "--dest-tls-verify=false"]
        self._run([*copy, f"docker://{ref}", f"docker://{image}:latest"])

    def _run(self, args: Sequence[str]) -> None:
        result = self._runner.run(args)
        if result.returncode != 0:
            raise PublishError(f"{args[0]} failed: {result.stderr}")
```

"""Gated OCI smoke (spec §9.3): build a multi-arch image once and push it to TWO
throwaway insecure local registries; assert skopeo resolves a multi-arch manifest
list on each. Proves build-once-push-many. Outside ``make ci`` (forge-smoke.yml).
"""

from __future__ import annotations

import json
import os
import shutil
import subprocess  # noqa: S404 — driving host buildah/skopeo/docker is the point
import time
from pathlib import Path

import pytest

from forge.packaging.runner import SubprocessRunner
from forge.publish.oci import OciPublisher

pytestmark = pytest.mark.skipif(
    os.environ.get("FORGE_DOCKER_TESTS") != "1"
    or any(shutil.which(t) is None for t in ("buildah", "skopeo", "docker")),
    reason="set FORGE_DOCKER_TESTS=1 with buildah+skopeo+docker",
)

_PORTS = (5000, 5001)
_NAME = "smoke_exporter"
_VERSION = "0.0.1"


def _emit_context(staging: Path) -> None:
    ctx = staging / _NAME
    ctx.mkdir(parents=True)
    (ctx / "Dockerfile").write_text(
        "FROM scratch\nARG TARGETARCH\nCOPY " + _NAME + "-${TARGETARCH} /app\n",
        encoding="utf-8",
    )
    for arch in ("amd64", "arm64"):
        (ctx / f"{_NAME}-{arch}").write_bytes(b"\x7fELF" + bytes(64))


def _start_registry(port: int) -> str:
    cid = subprocess.run(  # noqa: S603
        ["docker", "run", "-d", "-p", f"{port}:5000", "registry:2"],
        check=True,
        capture_output=True,
        text=True,
    ).stdout.strip()
    time.sleep(2)
    return cid


def _resolve_arches(port: int) -> set[str]:
    raw = subprocess.run(  # noqa: S603
        [
            "skopeo",
            "inspect",
            "--tls-verify=false",
            "--raw",
            f"docker://localhost:{port}/mh/{_NAME}:{_VERSION}",
        ],
        check=True,
        capture_output=True,
        text=True,
    ).stdout
    manifest = json.loads(raw)
    return {m["platform"]["architecture"] for m in manifest.get("manifests", [])}


def test_oci_multiarch_manifest_pushes_to_each_registry(tmp_path: Path) -> None:
    staging = tmp_path / "docker"
    _emit_context(staging)
    cids = [_start_registry(p) for p in _PORTS]
    try:
        OciPublisher(
            registries=[f"localhost:{p}/mh" for p in _PORTS],
            versions={_NAME: _VERSION},
            runner=SubprocessRunner(),
            tls_verify=False,
        ).publish(staging)

        for port in _PORTS:
            arches = _resolve_arches(port)
            assert {"amd64", "arm64"} <= arches, f"port {port}: {arches}"
    finally:
        for cid in cids:
            subprocess.run(  # noqa: S603
                ["docker", "rm", "-f", cid], check=False, capture_output=True
            )
```
