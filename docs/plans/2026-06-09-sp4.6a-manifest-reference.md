# SP4.6a — Manifest Reference (safe half) Implementation Plan

> **For agentic workers:** executed INLINE by the controller (docs + one anti-rot test; no mechanical TDD logic to delegate). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship a complete, machine-validated manifest reference (`docs/user-guide/manifest.reference.yaml`) in the current `kind`/`spec` Pydantic schema, plus a rewritten `manifest-reference.md`, so contributors have an authoritative example that cannot rot.

**Scope boundary:** This is SP4.6**a** only. The SP4.6**b** "first real forge-published release" (unfreeze catalogue → publish to prod gh-pages / GHCR / Docker Hub / Releases) is explicitly OUT of this pass — it is a separate gated operation requiring a dry-run, a legacy-gh-pages-mirror impact analysis, a rollback plan, and an explicit user go.

**Architecture:** One exhaustive, heavily-commented EXPORTER manifest (the dominant, most complex kind) that is a *valid* document (single coherent config: github upstream + binary_repack + rpm/deb/docker all enabled, every optional field populated). A pytest parses it through `parse_manifest` so `make ci` fails if a schema change makes the reference invalid. The dashboard kind and the mutually-exclusive variants (local upstream, alternative dashboard sources) are documented in the `.md` prose with snippets (they cannot coexist in one valid doc).

**Tech Stack:** Pydantic v2 manifest models, `forge.domain.manifest.parse_manifest`, `forge.sources.resolver.load_yaml_mapping`, pytest, container-first `./dev run`, `make ci`.

## Schema reference (from `src/forge/domain/manifest.py`, read 2026-06-09)

Envelope (`ManifestBase`): `kind`, `name`, `description`, `category="System"`, `version` (min_length=1), `license: str|None`.
Exporter `spec`: `upstream` + `build` + `artifacts`.
- `Upstream`: `type` Literal[github|local]; github→`repo` required; `strategy` Literal[latest_release]; `pin_major: int|None`; `archive_name: str|dict|None`; local→`local_binary` XOR `local_archive`.
- `Build`: `method` Literal[binary_repack|source_build]; `binary_name`; `extra_binaries: list[str]`; `extra_sources: list[{url,filename}]`; `archs=["amd64","arm64"]`.
- `artifacts.rpm` (`RpmTarget`): `enabled`, `targets`, `summary`, `install_path`, `dependencies`, `systemd`, `system_user`, `extra_files`, `directories`.
- `artifacts.deb` (`DebTarget`): same + `section="utils"`, `priority="optional"`.
- `artifacts.docker` (`DockerTarget`): `enabled`, `base_image`, `entrypoint`, `cmd`, `dockerfile`, `validation`.
- `Systemd`: `enabled`, `arguments`, `after=["network.target"]`, `restart="on-failure"`, `type="simple"`.
- `FileInstall`: `source`, `dest`, `mode="0644"`, `config=False`. `Directory`: `path`, `mode="0755"`, `owner="root"`, `group="root"`. `Validation`: `enabled=True`, `port`, `command`, `args`.
Dashboard `spec` (`DashboardSpec`): `source` (discriminated grafana|url|git|local) + `datasource: str|None` + `tags: list[str]`.

All models are `extra="forbid"`.

"""The shipped manifest reference must always parse under the current schema."""

from __future__ import annotations

from pathlib import Path

from forge.domain.manifest import ExporterManifest, parse_manifest
from forge.sources.resolver import load_yaml_mapping

_REFERENCE = Path(__file__).resolve().parents[2] / "docs" / "user-guide" / "manifest.reference.yaml"


def test_manifest_reference_is_a_valid_exporter() -> None:
    manifest = parse_manifest(load_yaml_mapping(_REFERENCE))
    assert isinstance(manifest, ExporterManifest)
    assert manifest.name
    assert manifest.spec.artifacts.rpm is not None
    assert manifest.spec.artifacts.deb is not None
    assert manifest.spec.artifacts.docker is not None
