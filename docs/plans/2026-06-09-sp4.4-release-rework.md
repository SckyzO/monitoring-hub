**Goal:** Rework `forge-release.yml` into a trigger-scoped per-item build matrix (`fail-fast: false`) that emits `entry.json` per item, joins them with `mh catalog assemble` (merging over the published catalogue), publishes serially, marks the run failed on any leg failure (native email), and self-heals missing legs via a daily reconcile job — wiring the `reconcile.missing_legs` helper (built SP4.2) into a new `mh catalog reconcile` CLI.

**Architecture:** One engine addition (`mh catalog reconcile` exposing `missing_legs`) + a full rewrite of `forge-release.yml`. The decoupled build/assemble commands (`mh build --entry-out`, `mh catalog assemble`) already exist (SP4.0). The matrix is scoped by trigger: push→changed items, schedule→missing items, dispatch/release→all items. Signing happens in each build cell (the `CatalogEntry` records the *signed* artifact's sha256/flag, so signing cannot be deferred to assemble). A gated smoke test proves the reconcile loop end-to-end.

**Tech Stack:** Python 3.12, Click + `CliRunner`, the `forge.detect.reconcile` helper, GitHub Actions, `actionlint`, `act`, container-first via `./dev run`, `make ci` on host.

## Locked decisions (Task 0)

1. **Engine surface = `mh catalog reconcile` only.** `mh build --entry-out`, `mh catalog assemble`, `mh catalog build` already exist (SP4.0); `missing_legs(manifests, catalog)` already exists (SP4.2) but had no CLI. This increment adds exactly one command.
2. **Build granularity = per item.** One matrix cell = `mh build <item> --sign-key … --entry-out ./entries`. The producer builds every target×arch leg of that item internally; per-leg failure isolation is the producer's concern, and `entry.json` carries whatever legs succeeded. `fail-fast: false` isolates *items* from each other. Reconcile rebuilds **whole items** that have any missing leg (idempotent re-emit) — leg-level rebuild selection is intentionally NOT implemented (YAGNI; whole-item rebuild produces the missing legs).
3. **Matrix is trigger-scoped** (the `detect` job decides):
   - `push` to `main` touching `catalog/**` → **changed** items (git diff `before..sha`).
   - `schedule` (every 6h, 4×/day) → **missing** items (reconcile).
   - `workflow_dispatch` → driven by a `mode` input:
     - `mode=reconcile` (default) → missing items — the on-demand "a job crashed, fix the holes" button.
     - `mode=all` → every item (`mh list --json`) — full rebuild, for testing the whole pipeline.
     - `mode=item` + `item=<name>` → that single item only.
   - `release: published` → **all** items.
   This is spec-coherent: `assemble` merges over the previous catalogue and keeps unbuilt items (§5 self-heal), which only makes sense when the matrix is a subset, not all-items-every-merge. Rebuilding all 35 items × ~10 legs on every bump merge would cost hours per merge for ~349 useless rebuilds; reconcile (cheap, idempotent, builds only the holes) is the self-healing safety net instead.
4. **`assemble` merges over the published catalogue.** Fetch `catalog.json` from the published Pages URL (env `FORGE_PUBLISHED_CATALOG_URL`, default `https://${owner}.github.io/${repo}/catalog.json`) with `curl -fsSL`; tolerate 404 (first publish → no `--previous`).
5. **Signing stays in the build cell.** Each build cell wraps key import + passphrase preset + `mh build --sign-key` in a single `./dev run bash -c` block (gpg-agent dies with the container, so import and sign cannot be split across `./dev run` calls — this is why the GPG preamble is duplicated in the build and assemble jobs; it is a constraint, not an anti-pattern). The assemble job re-imports for `mh repo build --sign` (repomd/Release signing). **Signing keys are release-pipeline only (post-merge, `main`); they never reach PR CI** (central SP4 constraint).
6. **Publishing is serialized.** Workflow-level `concurrency: { group: forge-release-publish, cancel-in-progress: false }` (queue, never cancel — a cancelled publish could leave a partial catalogue).
7. **A failed leg still fails the run.** `assemble` + publish jobs run `if: always()` so good legs publish, but a failed build matrix cell marks the whole run failed → GitHub's native "Actions failure" email on `main`. The assemble job appends `missing = expected − present` to `$GITHUB_STEP_SUMMARY`.
8. **Docker Hub stays OUT** — that is SP4.5. This increment keeps GHCR only.
9. **Actions SHA-pinned.** Reuse the SHAs already pinned in `forge-release.yml`; any new action is pinned by SHA (profile rule). `forge-smoke.yml` uses tag-pinned actions today — out of SP4.4 scope, left as-is.

## Deployment prerequisites (user infra, NOT blocking the merge)

- Branch protection on `main`: keep **"Require branches up to date before merging" OFF** (rebase destroys SSH signatures; `required_linear_history` already off).
- GPG secrets (`GPG_PRIVATE_KEY`, `GPG_PASSPHRASE`) already exist (used by the current `repo` job).
- Optional: set repo variable/secret `FORGE_PUBLISHED_CATALOG_URL` if Pages is served from a custom domain. Until the first publish (SP4.6) the fetch 404s harmlessly.

Add this command immediately after `catalog_assemble` (after its closing `click.echo(...)`):

```python
@catalog.command(name="reconcile")
@_catalog_root_option
@click.option(
    "--catalog",
    "catalog_path",
    type=click.Path(dir_okay=False, path_type=Path),
    default=None,
    help="Published catalog.json to diff against (omit to treat everything as missing).",
)
@click.option("--json", "as_json", is_flag=True, help="Emit machine-readable JSON.")
def catalog_reconcile(catalog_root: str | None, catalog_path: Path | None, as_json: bool) -> None:
    """Report missing = expected(manifest matrix) - present(catalog) legs (spec §7).

    ``--json`` emits ``{"missing": [{item,type,target,arch}], "items": [names]}``;
    the reconcile workflow drives its build matrix from ``items`` and renders
    ``missing`` into the run's step summary. No writes.
    """
    discover()
    root = resolve_catalog_root(catalog_root)
    manifests = [parse_manifest(load_yaml_mapping(p)) for p in iter_manifest_paths(root)]
    catalog = load_catalog(catalog_path) if catalog_path is not None else None
    legs = missing_legs(manifests, catalog)
    items = sorted({leg.item for leg in legs})

    if as_json:
        click.echo(
            jsonlib.dumps(
                {
                    "missing": [
                        {"item": x.item, "type": x.type, "target": x.target, "arch": x.arch}
                        for x in legs
                    ],
                    "items": items,
                },
                indent=2,
            )
        )
        return

    if not legs:
        click.echo("all legs present")
        return
    for leg in legs:
        click.echo(f"{leg.item}\t{leg.type}\t{leg.target or '-'}\t{leg.arch or '-'}")
    click.echo(f"{len(legs)} missing leg(s) across {len(items)} item(s)")
```

Note: `discover()` is required so `parse_manifest` resolves the exporter kind. `load_catalog`, `iter_manifest_paths`, `resolve_catalog_root`, `parse_manifest`, `load_yaml_mapping`, `jsonlib` are already imported in `main.py` — verify and only add the `missing_legs` import.

```yaml
name: forge-release

# Release pipeline (spec §5-§7): trigger-scoped per-item build matrix (fail-fast)
# -> emits entry.json per item -> mh catalog assemble (merge over published
# catalogue) -> signed repo trees -> deploy Pages || publish Releases || GHCR.
# A failed leg still fails the run (native email); missing = expected - present
# is listed in the step summary and self-healed by the daily reconcile run.
# All tooling runs in the dev image via ./dev run; secrets reach the container
# through the env allowlist in ./dev (never argv). Actions pinned by SHA.

on:
  push:
    branches: [main]
    paths: ["catalog/**"]
  schedule:
    - cron: "17 */6 * * *" # reconcile (missing legs), 4x/day
  release:
    types: [published]
  workflow_dispatch:
    inputs:
      mode:
        description: "reconcile (holes only) | all (full rebuild) | item (single)"
        type: choice
        default: reconcile
        options: [reconcile, all, item]
      item:
        description: "Single item to rebuild (required when mode=item)"
        type: string
        default: ""

permissions:
  contents: read

# Serialize publishing: never cancel (a cancelled publish could leave a partial
# catalogue); queued runs apply in order.
concurrency:
  group: forge-release-publish
  cancel-in-progress: false

jobs:
  detect:
    runs-on: ubuntu-latest
    outputs:
      items: ${{ steps.pick.outputs.items }}
    steps:
      - uses: actions/checkout@df4cb1c069e1874edd31b4311f1884172cec0e10 # v6.0.3
        with:
          fetch-depth: 0
      - name: Build dev image
        run: ./dev build
      - name: Sync dependencies
        run: make sync
      - name: Fetch published catalogue (for reconcile diff)
        env:
          CATALOG_URL: ${{ vars.FORGE_PUBLISHED_CATALOG_URL || format('https://{0}.github.io/{1}/catalog.json', github.repository_owner, github.event.repository.name) }}
        run: |
          if curl -fsSL "$CATALOG_URL" -o published-catalog.json; then
            echo "fetched published catalogue"
          else
            echo "no published catalogue yet"
          fi
      - name: Pick items to build (trigger-scoped)
        id: pick
        env:
          EVENT_NAME: ${{ github.event_name }}
          BASE_SHA: ${{ github.event.before }}
          HEAD_SHA: ${{ github.sha }}
          MODE: ${{ github.event.inputs.mode }}
          ITEM: ${{ github.event.inputs.item }}
        run: |
          set -euo pipefail
          reconcile_items() {
            if [ -f published-catalog.json ]; then
              ./dev run uv run mh catalog reconcile \
                --catalog published-catalog.json --json | jq -c '.items'
            else
              ./dev run uv run mh catalog reconcile --json | jq -c '.items'
            fi
          }
          all_items() { ./dev run uv run mh list --json | jq -c '[.[].name]'; }
          case "$EVENT_NAME" in
            push)
              # Changed items only (one bump PR touches one manifest path).
              items=$(git diff --name-only "$BASE_SHA" "$HEAD_SHA" -- 'catalog/**' \
                | sed -n 's#^catalog/[^/]*/\([^/]*\)/manifest\.yaml$#\1#p' \
                | sort -u | jq -R . | jq -cs .)
              ;;
            schedule)
              items=$(reconcile_items)
              ;;
            workflow_dispatch)
              case "$MODE" in
                all) items=$(all_items) ;;
                item)
                  if [ -z "$ITEM" ]; then
                    echo "mode=item requires the 'item' input" >&2
                    exit 1
                  fi
                  items=$(jq -cn --arg i "$ITEM" '[$i]')
                  ;;
                *) items=$(reconcile_items) ;; # reconcile (default)
              esac
              ;;
            *)
              items=$(all_items) # release -> full rebuild
              ;;
          esac
          echo "items=$items" >> "$GITHUB_OUTPUT"
          echo "selected: $items"

  build:
    needs: detect
    if: needs.detect.outputs.items != '[]'
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        item: ${{ fromJSON(needs.detect.outputs.items) }}
    steps:
      - uses: actions/checkout@df4cb1c069e1874edd31b4311f1884172cec0e10 # v6.0.3
      - name: Build dev image
        run: ./dev build
      - name: Sync dependencies
        run: make sync
      - name: Build + sign one item, emit entry.json
        env:
          GPG_PRIVATE_KEY: ${{ secrets.GPG_PRIVATE_KEY }}
          GPG_PASSPHRASE: ${{ secrets.GPG_PASSPHRASE }}
          ITEM: ${{ matrix.item }}
        run: |
          ./dev run bash -c '
            set -euo pipefail
            export GNUPGHOME="$PWD/.gnupg-ci"
            install -d -m 700 "$GNUPGHOME"
            echo "allow-preset-passphrase" > "$GNUPGHOME/gpg-agent.conf"
            gpg-connect-agent reloadagent /bye
            printf "%s" "$GPG_PRIVATE_KEY" | gpg --batch --import
            key_id=$(gpg --list-secret-keys --with-colons | awk -F: "/^sec/{print \$5; exit}")
            grip=$(gpg --list-secret-keys --with-keygrip --with-colons \
              | awk -F: "/^grp/{print \$10; exit}")
            preset=$(command -v gpg-preset-passphrase \
              || echo /usr/libexec/gpg-preset-passphrase)
            "$preset" --preset --passphrase "$GPG_PASSPHRASE" "$grip"
            uv run mh build "$ITEM" \
              --sign-key "$key_id" --work-dir ./dist --entry-out ./entries
          '
      - name: Upload entry.json
        uses: actions/upload-artifact@043fb46d1a93c77aae656e7c1c64a875d1fc6a0a # v7.0.1
        with:
          name: entry-${{ matrix.item }}
          path: entries/
          retention-days: 1
      - name: Upload dist (signed packages + docker contexts)
        uses: actions/upload-artifact@043fb46d1a93c77aae656e7c1c64a875d1fc6a0a # v7.0.1
        with:
          name: dist-${{ matrix.item }}
          path: dist/
          retention-days: 1
```
