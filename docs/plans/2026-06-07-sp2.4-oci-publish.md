# SP2.4 — OCI publish + Docker context rebalance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline).
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Docker image creation out of `mh build` (daemon-bound, untestable
in `make ci`) into a daemonless flow: `mh build` emits a build *context* to disk,
and a new gated `mh publish --oci` builds/pushes multi-arch images via
buildah/skopeo. Remove the SP1 `DockerBuilder`.

**Architecture:** `packaging/docker.py` keeps the pure Dockerfile renderer but
swaps `DockerBuilder` (docker CLI) for `emit_docker_context` (pure file gen).
`publish/oci.py` adds `OciPublisher` (buildah/skopeo via injected runner). The
exporter producer emits **one** context per image and **one** `docker-image`
artifact per exporter; `mh publish --oci` dispatches to `OciPublisher`.

**Tech Stack:** Python 3.12, Pydantic v2, Click, buildah + skopeo (gated),
pytest. All tooling via `./dev run`; `make ci` on host.

---

## Locked design decisions

- **Multi-arch context layout = Option A (one context per image, TARGETARCH).**
  `mh build` emits `<work_dir>/docker/<name>/` holding the rendered `Dockerfile`
  (declares `ARG TARGETARCH`, `COPY <binary>-${TARGETARCH} /usr/bin/<binary>`)
  plus one binary per arch (`<binary>-amd64`, `<binary>-arm64`). One
  `docker-image` artifact per exporter (`target=<name>:<version>`, `arch=None`).
- **`OciPublisher` derives arches from the context** (`*-amd64` / `*-arm64`
  present) → single-arch exporters build only their arch. Standard set
  `("amd64", "arm64")` (matches spec §5.7).
- **Image ref** = `f"{registry}/{name}"`, tags `:<version>`, `:<version>-<arch>`
  (per-arch build stage), `:latest`. Default registry
  `ghcr.io/sckyzo/monitoring-hub` (spec §6).
- **Daemonless guarantee:** `emit_docker_context` takes **no runner** — `mh build`
  invokes no docker/buildah command (unit-asserted).
- **Docker `Artifact.url` stays `None` at repo-build** (no registry known there);
  populating the catalog with the OCI ref is out of SP2.4 scope (spec §10 lists
  url population generically; `mh repo build` has no `--registry`). Deferred.
- **`mh publish`** ships with `--oci` only; `--releases` lands in SP2.5 (no dead
  flag now).
- **Versions for tagging** come from `catalog.json` (`name → version`), loaded by
  the `mh publish` command and injected into `OciPublisher`.

```python
from collections.abc import Mapping

from forge.domain.version import clean_version


def emit_docker_context(
    manifest: ExporterManifest,
    *,
    binaries: Mapping[str, Path],
    out_dir: Path,
    manifest_dir: Path | None = None,
) -> Artifact:
    docker = manifest.spec.artifacts.docker
    if docker is None or not docker.enabled:
        raise BuildError(f"manifest {manifest.name!r} has no enabled docker target")
    if docker.dockerfile is not None:
        if manifest_dir is None:
            raise BuildError(
                f"{manifest.name!r}: docker.dockerfile is set but no manifest_dir to resolve it"
            )
        content = render_template(manifest_dir / docker.dockerfile, _template_context(manifest))
    else:
        content = render_dockerfile(manifest)
    out_dir.mkdir(parents=True, exist_ok=True)
    dockerfile = out_dir / "Dockerfile"
    dockerfile.write_text(content, encoding="utf-8")
    binary_name = manifest.spec.build.binary_name
    for arch, src in binaries.items():
        shutil.copy2(src, out_dir / f"{binary_name}-{arch}")
    return Artifact(
        type="docker-image",
        target=f"{manifest.name}:{clean_version(manifest.version)}",
        arch=None,
        sha256=file_sha256(dockerfile),
        signed=False,
    )
```

Drop the now-unused `CommandRunner`, `json` stays (renderer). Keep
`render_dockerfile`, `_template_context`.

```python
_ARCHES = ("amd64", "arm64")


class OciPublisher:
    def __init__(self, *, registry: str, versions: Mapping[str, str], runner: CommandRunner) -> None:
        self._registry = registry
        self._versions = versions
        self._runner = runner

    def publish(self, staging: Path) -> None:
        for context in sorted(p for p in staging.iterdir() if p.is_dir()):
            self._publish_one(context)

    def _publish_one(self, context: Path) -> None:
        name = context.name
        version = self._versions[name]
        image = f"{self._registry}/{name}"
        ref = f"{image}:{version}"
        arches = [a for a in _ARCHES if any(context.glob(f"*-{a}"))]
        for arch in arches:
            self._run(["buildah", "bud", "--arch", arch, "-t", f"{ref}-{arch}", str(context)])
        self._run(["buildah", "manifest", "create", ref])
        for arch in arches:
            self._run(["buildah", "manifest", "add", ref, f"{ref}-{arch}"])
        self._run(["buildah", "manifest", "push", "--all", ref, f"docker://{ref}"])
        self._run(["skopeo", "copy", f"docker://{ref}", f"docker://{image}:latest"])

    def _run(self, args: list[str]) -> None:
        result = self._runner.run(args)
        if result.returncode != 0:
            raise PublishError(f"{args[0]} failed: {result.stderr}")
```

Imports: `Mapping`, `Path`, `CommandRunner`, `PublishError`.

```python
@cli.command()
@click.option("--oci", is_flag=True, help="Build + push multi-arch OCI images.")
@click.option("--registry", default=_DEFAULT_OCI_REGISTRY, show_default=True)
@click.option("--contexts", "contexts_dir", type=click.Path(file_okay=False, path_type=Path),
              default=Path("dist/docker"), show_default=True,
              help="Directory of <name>/ docker build contexts (from mh build).")
@click.option("--catalog", "catalog_path", type=click.Path(dir_okay=False, path_type=Path),
              default=Path("catalog.json"), show_default=True)
def publish(oci: bool, registry: str, contexts_dir: Path, catalog_path: Path) -> None:
    """Publish built artifacts to remote hosts (OCI now; releases in SP2.5)."""
    if not oci:
        raise click.UsageError("nothing to publish: pass --oci")
    catalog = load_catalog(catalog_path)
    if catalog is None:
        raise click.ClickException(f"catalog not found: {catalog_path}")
    versions = {item.name: item.version for item in catalog.items}
    OciPublisher(registry=registry, versions=versions, runner=SubprocessRunner()).publish(contexts_dir)
    click.echo(f"published {len(versions)} image(s) to {registry}")
```
